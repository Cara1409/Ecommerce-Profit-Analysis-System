# Sistema de Análisis de Rentabilidad - E-commerce de Suplementos

## 🎯 Objetivo
Transformar datos de ventas en una herramienta de decisión financiera para calcular el margen neto real, considerando comisiones de plataformas y costos logísticos.

## 🛠️ Stack Tecnológico
- **Python**: Generación de datos sintéticos y ETL.
- **SQL Server**: Modelado de datos (Esquema en Estrella).
- **Power BI**: Visualización de KPIs financieros.
